# Оно тебе надо

Лендинг для аукциона

## Контекст проекта

**Учебный проект от [Яндекс Практикум](https://practicum.yandex.ru/)**
- **Макет предоставлен:** Яндекс Практикум
- **Задача:** Реализовать адаптивный лендинг по готовому дизайну

## О проекте

- **Технологии:** HTML5, CSS3 (Flexbox/Grid), БЭМ методология
- **Статус:** Завершен
- **Тип проекта:** Адаптивный лендинг
- **Демо:** [Открыть проект](https://legion13-alt.github.io/ono-tebe-nado)

## Техническая реализация

### **Что сделано:**
- **Чистая семантическая вёрстка** - правильные HTML-теги, доступность
- **Адаптивный дизайн** - гибкий текст и отступы, подстраивающиеся под любой экран
- **Pixel-perfect** - точное соответствие макету
- **Современный CSS** - Flexbox и Grid для сложных раскладок
- **БЭМ методология** - компонентный подход к стилям

### **Особенности верстки:**
- Адаптивные карточки и сетки
- Оптимизация для мобильных устройств
- Читаемая типографика
